Project Statement

Project Title

Password Manager Using Java

Problem Statement

It can be difficult to manage ones own online account passwords when a person uses numerous accounts and creates passwords with low complexity

These problems are exacerbated when people store their account data in random places, or using easily accessible word documents to save them in plaintext.

The purpose of this project is to design a console based password manager that would store ones account credentials together in one encrypted place, and provide a simple risk assessment for each password.

Scope

This project is intended to be a minimalistic academic application written in java that would store both web and financial accounts with the ability to check, update, delete, or mask ones sensitive data with a certain level of security and save it to a file in encrypted form.

The project's scope is limited to a basic proof-of-concept design that does not intend to offer advanced security features like encryption or a graphical user interface.

Target Users

The target users for this application would be students or those interested in learning how such programs can be created in java.

Main Features

The following are the main features of the proposed application:

1. The ability to add a web account;

2. The ability to add a financial account;

3. The ability to view ones account data;

4. The ability to assess password strength;

5. The ability to update ones password;

6. The ability to delete ones account;

7. The ability to save encrypted records;

8. An optional feature to implement an auto-lock function after a certain period of time.

Java Concepts

The following core java concepts will be implemented in the project:

1. Object-oriented programming (OOP) concepts such as encapsulation, inheritance, abstraction, interfaces, and polymorphism;

2. The method overloading, custom exception handling, collection, file IO, and multithreading concepts.

Expected Outcome

The end result of the project is a simple console based password manager that can accept a users input, take account data, reject weak or invalid input, provide an adequate risk assessment, and store the data with masked fields to protect the user's private information.
